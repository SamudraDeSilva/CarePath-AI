# v0.1.1 - System Architecture & Foundations

Initial public milestone with the portability patch. Implements a 14-table SQLite foundation, reusable Python services, three fictional demo patients, consent and staff approval checks, simulated communication and transport workflows, architecture and ERD diagrams, and an executed notebook. The patch explicitly closes a temporary SQLite connection and improves UTF-8 and test diagnostics.

Original verification: **28/28 tests passed**, zero foreign-key violations. Windows was not directly tested. Risk scores are illustrative placeholders, not trained predictions. No clinical validation or live integration.
